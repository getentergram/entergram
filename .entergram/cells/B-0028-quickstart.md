# Quickstart

## What
```bash
# 1. Install
npm install -g entergram        # or: curl -fsSL https://entergram.dev/install | bash

# 2. Learn your repo (git history + docs → memory)
cd your-project
entergram init
entergram learn

# 3. Connect your agent (below), then just code — it remembers.
```
