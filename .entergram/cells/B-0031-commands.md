# Commands

## What
| Command | Does |
|---|---|
| `entergram init` | Scaffold memory in the current repo |
| `entergram learn` | Ingest git history + docs into memory (incremental) |
| `entergram recall "<q>"` | Test what the agent would retrieve |
| `entergram remember "<fact>"` | Write a fact by hand |
| `entergram review` | Triage auto-extracted facts (accept / edit / reject) |
| `entergram doctor` | Health + coverage check |
| `entergram serve` | Run the MCP server for your agent |
